# WRAPPER

Same company name. Different legal product. Pick the mint, then buy it on this page.

Live idea for Solana Stocklana: tokenized stocks on Solana are not interchangeable. SpaceX alone has four wrappers (Backpack entitlement, xStocks tracker, Tessera loan token, PreStocks SPV). WRAPPER compares them, then runs a Jupiter Ultra swap locked to the chosen mint.

## What is wired

- PreStocks catalog — https://prestocks.com/api/prestocks
- Tessera T-tokens — tSpaceX, tOpenAI, tKalshi
- Pyth Hermes — equity feed id + NY session hours
- Jupiter Plugin — on-page swap, output mint fixed
- Meteora DBC + Clawpump — linked from the selected mint

## Run

```
npm install
npm run dev
```
